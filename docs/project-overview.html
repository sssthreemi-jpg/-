프로젝트 개요

기존 PPT 성과발표 방식의 한계를 해결하는 인터랙티브 대시보드

🎯 핵심 목표

  • 드릴다운 분석 — 전사 → 사업부 → 품목 → 품목코드까지 즉시 탐색
  • 전년동기비 비교 — 모든 수치에 대한 증감 분석 자동 표시
  • 실시간 발표 지원 — 평가자가 발표 중 세부 질문 시 즉시 데이터 확인
  • 모바일 대응 — 휴대폰에서도 동일한 분석 기능 제공

📊 분석 범위

  • 사업부 7개 — ETC, CH, 건기식, 나보타, 글로벌, 수탁, 기타
  • 손익 항목 44개 — 매출 → 매출원가 → 비용(7종) → R&D → 영업이익
  • 기간 — 분기별(1Q~4Q) 및 연간 분석, 최근 3분기/3개년 추이
  • 비용 세부항목 — 전표 레벨(구분3) 드릴다운 지원

구현된 화면

현재 개발 완료된 5개 페이지의 주요 기능

1

전사 손익 총괄

/ (메인)

전사 기준 손익계산서를 분기별/연간으로 조회하고, 사업부별 매출 구성을 드릴다운하는 메인 페이지입니다.

  • 연도/분기 선택으로 기간 전환 (1Q~4Q, 연간)
  • 전년동기 + 직전 3분기(또는 3개년) 추이 표시
  • 전년동기比 증감 금액 + 매출비 %p 자동 계산
  • 매출/매출원가 클릭 → 사업부별 금액 펼침
  • 비용 항목 클릭 → 세부항목(level1) 아코디언
  • 사업부 클릭 → 사업부별 손익 페이지로 이동

사업부별 손익

/division

개별 사업부의 손익을 상세 분석하고, 매출/원가를 품목 단위까지 드릴다운합니다.

  • 사업부 탭 전환 (ETC/CH/건기식/나보타/글로벌/수탁/기타)
  • 사업부별 손익 테이블 (전사 손익과 동일 구조)
  • 매출/매출원가 클릭 → 품목 드릴다운 패널 표시
  • 사업부별 맞춤 드릴다운 계층 (제상→중분류→수익군→품목구분)
  • 매출 증감 요인 워터폴 차트 (상위 증/감 품목)
  • 품목구분 선택 → 품목 상세 패널 (월별 추이, 원가율, 품목코드)

원가 분석

/cost

사업부별 원가율을 비교 분석하고, 분기 추이 및 품목별 원가 구조를 파악합니다.

  • 분기별 원가율 추이 라인 차트 (최근 8분기)
  • 사업부별 원가율 비교 바 차트 (당기 vs 전년)
  • 사업부별 원가율 테이블 (매출/원가/원가율/전년비)
  • 사업부 클릭 → 품목별 원가율 상세 테이블
  • 원가율 증감 색상 표시 (개선=파랑, 악화=빨강)

비용 분석

/expense

7개 비용 대분류별 현황과 전년비를 분석하고, 전표 레벨까지 세부 드릴다운합니다.

  • KPI 카드 (총 비용, 매출대비 비율, R&D비용, 영업판관비)
  • 비용 대분류별 비교 바 차트 (당기 vs 전년)
  • 비용 항목별 전년비 증감 차트 (증가=빨강, 감소=파랑)
  • 비용 항목 확장 → 세부항목(level1) 아코디언
  • "상세" 버튼 → RAW(E) 전표 기반 구분3 드릴다운 패널
  • 구분3 → 사업구분별(직접/공통) 내역 차트+테이블
  • 사업부별 비용 배분 교차 테이블

피드백 요청 사항

아래 항목에 대해 의견을 주시면 반영하겠습니다

1. 화면 구성

페이지 간 네비게이션 구조가 직관적인가? 추가되어야 할 화면이 있는가?

2. 드릴다운 깊이

현재 드릴다운 단계가 적절한가? 더 깊거나 얕아야 할 항목이 있는가?

3. 데이터 표시

금액/비율 포맷, 증감 색상 표시, 비교 기간 설정이 적절한가?

4. 차트 구성

워터폴/라인/바 차트 외 추가 시각화가 필요한 항목이 있는가?

5. 모바일 사용성

휴대폰에서 확인할 때 불편한 점이 있는가? 테이블 스크롤 방향 등

6. 기타 요구사항

발표 시 필요한 추가 기능 (인쇄, PDF 내보내기, 특정 뷰 등)
