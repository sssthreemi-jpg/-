> 최종 정리일: 2026-03-31

## 1. 프로젝트 개요

제약회사 본부장 성과발표용 인터랙티브 웹 대시보드.
React(Vite) + Tailwind CSS v4 + Recharts 기반 SPA + Express 챗봇 백엔드.
폰트: Wanted Sans Variable (CDN 웹폰트).

## 4. 영역별 구현 상태

### 4-A. 프론트엔드 — 대시보드 (✅ 완료)

#### CompanySummary.jsx (전사 손익 총괄)
- 연도 셀렉트 + 분기 탭 (1Q~4Q, 연간)
- P&L 테이블: 전년동기 / 직전3분기(연간은 직전3개년) / 당기 / 전년동기比
- 2단 헤더 구조 (그룹 헤더 + 서브 헤더)
- 금액 + 매출대비 비율 가로 배치
- 하이라이트 행: 매출총이익, R&D차감전이익, 영업이익
- 드릴다운: 매출/매출원가 → 사업부별 행 펼침, 비용 → 하위항목 아코디언

#### DivisionPL.jsx (사업부별 손익)
- 사업부 탭 (ETC, CH, 건기식, 나보타, 글로벌, 수탁, 기타) + 색상 구분
- P&L 테이블 + 품목 드릴다운 (사업부별 계층 DRILL_CONFIG)
- KPI 카드 + 핵심 품목 테이블 + 신호등 상태
- URL 파라미터: `?division=ETC&focus=매출원가`

#### CostRateAnalysis.jsx (원가 분석)
- 최근 8분기 원가율 추세 라인차트
- 사업부별 원가율 비교 바차트 + 테이블
- 사업부 선택 → 품목별 원가율 상세 (상위 20개)

#### ExpenseAnalysis.jsx (비용 분석)
- KPI 카드 4개 (총비용, 매출대비비율, R&D, 영업판관비)
- 비용 구성/증감 바차트
- 비용 항목 아코디언 → ExpenseDrilldown 패널 (구분3 상세)

## 6. 데이터 구조

```json
{
  "data": [
    { "year": 2025, "month": 1, "type": "actual",
      "items": {
        "전사": { "매출": 3162, "매출원가": 1538, ... },
        "ETC": { "매출": 1200, ... },
        ...
      }
    }
  ]

```
- 단위: 억원
- 사업부: 전사, ETC, CH, 건기식, 나보타, 글로벌, 수탁, 기타

### sales_cost_summary.json
```json
[
  { "year": 2025, "month": 1,
    "division": "ETC", "category": "제상", "productGroup": "중분류명",
    "sales": 금액(원), "cost": 금액(원), ... }
]
```

### sales_cost_raw.json (~310MB, lazy-load)
```json
[
  { "productCode": "코드", "productName": "품목명",
    "productGroup": "품목구분", "division": "ETC",
    "year": 2025, "month": 1, "sales": 원, "cost": 원 }
]
```

### expense_detail.json
```json
[
  { "year": 2025, "month": 1,
    "category2": "영업판관비", "category3": "세부항목명",
```
