# 손익 드릴다운 레포트 - 설계 명세서

## 1. 프로젝트 개요

### 목적
기존 본부장 성과발표 PPT(엑셀 표 붙여넣기 수준)를 대체하여, 평가자가 발표 중 궁금한 부분을 **드릴다운**으로 즉시 확인할 수 있는 인터랙티브 웹 대시보드 구축

### 핵심 원칙
- 기존 PPT 성과발표 자료와 **동일한 정보 흐름** 유지 (전사→사업별→품목별)
- 상위 레벨에서 숫자 클릭 시 하위 레벨로 드릴다운
- 분기/연간 단위 조회 + 전년동기비 비교

### 기술 스택
- **프론트엔드**: React (SPA)
- **데이터**: JSON 파일 분리 (분기별 교체 가능)
- **차트**: Recharts 또는 Chart.js
- **스타일**: Tailwind CSS

## 2. 데이터 소스 및 구조

### 2-1. 원본 파일

| 파일 | 용도 | 단위 | 시트 |
|------|------|------|------|
| 월별손익.xlsx | 사업부별 월별 손익계산서 | 억원 | 실적(2020~2025), 26년목표 |
| S_C_raw.xlsx | 품목별 매출/원가 상세 | 원 | 요약(품목구분2 레벨), RAW(품목코드 레벨) |
| RAW_E_{연도}.xlsx | 비용 전표 상세 (배부 전) | 원 | RAW(E), 마케팅비용, 판매대행수수료, EGF로열티, 법무비용, 조견표(R&D) |

> RAW_E 파일은 연도별로 분리 (2022~2025). 비용 드릴다운의 구분3 레벨 분석에 사용.

### 2-2. 데이터 관계 및 드릴다운 가능 범위

```
┌─────────────────────────────────────────────────────────────────────┐
│  월별손익.xlsx (사업부 단위, 억원)                                      │
│  ┌───────────────────┐   ┌──────────────────────────────────┐      │
│  │ 매출 (No.1~3)      │══ │ S_C_raw.xlsx 품목별 합산과 1:1 일치 │      │
│  │ 매출원가 (No.4~5)   │══ │ → 품목별 드릴다운 가능 ✅           │      │
│  └───────────────────┘   └──────────────────────────────────┘      │
│  ┌───────────────────┐                                             │
│  │ 매출총이익 (No.6)   │ ← 매출 - 매출원가 (산출)                     │
│  └───────────────────┘                                             │
│  ┌───────────────────┐   ┌──────────────────────────────────┐      │
│  │ 비용 (No.7~39)     │══ │ RAW_E.xlsx 구분3(세부항목) 레벨로     │      │
│  │ (영업판관비,판매대행, │   │ 드릴다운 가능 ✅                    │      │
│  │  매출변동비,관리비,  │   │ (구분2→구분3→사업구분별 분해)         │      │
│  │  일반관리비,비경상)  │   │ 단, 품목별 비용 배분은 불가 ⚠️       │      │
│  └───────────────────┘   └──────────────────────────────────┘      │
│  ┌───────────────────┐                                             │
│  │ R&D비용 (No.41~43) │ ← 배부 결과 금액만 표시 (R/D 구분)             │
│  │ 영업이익 (No.44)   │ ← R&D차감전이익 - R&D = 사업부 단위             │
│  └───────────────────┘                                             │
└─────────────────────────────────────────────────────────────────────┘
```

**핵심**:
- 매출/원가는 S_C_raw에 품목별 데이터가 있어 드릴다운 가능
- 비용은 RAW(E)에 전표 단위 원천 데이터가 있어 구분3(세부항목) 레벨까지 드릴다운 가능
- 단, 비용의 품목별 배분은 불가 (비용은 코스트센터/부서 단위이지 품목 단위가 아님)

단위 변환: S_C_raw(원) ÷ 100,000,000 = 월별손익(억원), RAW_E(원) ÷ 100,000,000 = 월별손익(억원)

## 3. 화면 구성 및 드릴다운 경로

### 3-1. 메인 네비게이션

상단 탭 또는 좌측 사이드바:
- **전사 손익** (메인 대시보드)
- **매출/원가 분석** (품목별 드릴다운 가능 — S_C_raw 기반)
- **비용 분석** (구분3 세부항목까지 드릴다운 — 월별손익 + RAW(E) 기반)

### 3-2. 드릴다운 계층 구조

#### 매출/원가 드릴다운 (S_C_raw 기반 — 품목 레벨까지 가능)

```
[Level 0] 전사 손익 총괄
  ├─ 매출/매출원가/매출총이익/영업이익 요약 테이블 (PPT 슬라이드2 대응)
  ├─ 분기별 추이 차트
  └─ 사업부별 매출 비중 파이차트 또는 바차트
      │
      ▼ (사업부 클릭)
[Level 1] 사업별 손익 상세
  ├─ 해당 사업부의 매출~영업이익 전체 손익 테이블 (월별손익 데이터)
  ├─ 전년동기비 증감
  └─ 매출/원가 구성 요약 (중분류별) ← 여기서부터 S_C_raw 기반
      │
      ▼ (중분류 또는 수익군 클릭)
[Level 2] 품목그룹별 매출/원가
  ├─ ETC의 경우: 자체/코프로/라이선스 → 수익군(가/나/다/라)별
  ├─ 나보타의 경우: 국내/수출 → 국가별
  ├─ CH의 경우: 명품군/기타품목별
  ├─ 건기식의 경우: 품목군별 (에너씨슬, 닥터베어 등)
  ├─ 글로벌의 경우: 국가별 (중국/태국/필리핀 등)
  └─ 수탁의 경우: 관계사수탁/외부수탁별
      │
      ▼ (품목 클릭)
[Level 3] 품목구분2 레벨 상세
  ├─ 개별 품목의 월별 매출/원가 추이
  ├─ 원가율 변동
  └─ (확장) 품목코드 레벨까지 드릴다운 가능
```

#### 비용 분석 (월별손익 + RAW(E) 기반 — 구분3 세부항목까지)

```
[Level 0] 전사 비용 총괄 (월별손익 — PPT 비용분석 슬라이드와 동일 형태)
  ├─ 비용 항목 대분류별 금액/비율 (영업판관비, 판매대행수수료, 매출변동비, 관리비 등)
  └─ 전년동기비 증감
      │
      ▼ (비용 항목 클릭)
[Level 1] 세부 비용항목별 분석 (RAW(E) 구분3)
  ├─ 구분3별 금액 (영업비용, 마케팅비용, 영업인건비, 광고비 등)
  └─ 각 구분3별 직접귀속/공통 비중 표시
      │
      ▼ (세부 항목 클릭)
[Level 2] 사업구분별 내역
  ├─ 해당 구분3의 사업구분(ETC/CH/나보타/공통 등)별 금액
  └─ 전년동기비 증감
      │
      ✕ 여기까지 (코스트센터/원가요소 레벨은 제공하지 않음)
```

> **설계 원칙**: 기본 화면은 PPT 비용분석 슬라이드와 동일한 형태를 유지합니다.
> 드릴다운 시 RAW(E)의 구분3(세부항목) 레벨까지 확인 가능합니다.
> R&D비용은 배부 결과(월별손익)의 R(연구)/D(개발) 금액만 표시합니다.

### 3-3. 각 화면 상세

#### 화면 ①: 전사 손익 총괄 (PPT 슬라이드 2 대응)

| 요소 | 설명 |
|------|------|
| 기간 선택기 | 분기(25.1Q, 25.2Q...) / 누적(상반기, 3분기누적, 연간) / 월별 토글 |
| 전사 요약 카드 | 매출, 영업이익, 영업이익률 대형 숫자 표시 + 전년동기비 증감 |
| 전사 손익 테이블 | 44행 손익 항목 × 사업부별 금액 (기존 PPT 엑셀표와 동일 구조) |
| 사업부별 매출 비중 차트 | 바 또는 도넛 차트 |
| 분기별 추이 차트 | 매출/영업이익 라인 차트 (최근 8분기) |

**인터랙션**: 테이블의 사업부명 클릭 → Level 1로 이동

#### 화면 ②: 사업별 매출/원가 드릴다운 (PPT 슬라이드 4~7 대응)

| 요소 | 설명 | 데이터 소스 |
|------|------|-----------|
| 사업부 선택 탭 | ETC / CH / 건기식 / 나보타 / 글로벌 / 수탁 | - |
| 사업부 손익 요약 | 해당 사업부 매출~영업이익 카드 | 월별손익 |
| 매출/원가 구성 테이블 | 중분류별(또는 수익군별) 매출/원가/원가율 | S_C_raw |
| 전년동기비 워터폴 차트 | 매출 증감 요인 시각화 | S_C_raw |

> 손익 요약(매출→영업이익)은 월별손익 데이터를 사용하고,
> 매출/원가의 품목별 드릴다운은 S_C_raw 데이터를 사용합니다.
> 비용 항목(영업판관비~R&D)은 사업부 단위 금액만 표시됩니다.

**ETC 특화 뷰**:
- 제품/상품 구분 → 자체/코프로/라이선스 → 수익군(가/나/다/라)
- PPT "매출 분석_ETC 수익군별" 슬라이드와 동일한 정보

**나보타 특화 뷰**:
- 국내/수출 구분 → 국가별 매출/원가 테이블
- PPT "매출 분석_나보타 국가별" 슬라이드와 동일한 정보

#### 화면 ③: 품목별 상세 (Level 2~3)

| 요소 | 설명 |
|------|------|
| 품목 리스트 | 품목구분2별 매출/원가/원가율 테이블 (정렬 가능) |
| 월별 추이 | 선택 품목의 월별 매출/원가 라인차트 |
| 전년비교 | 전년 동월 대비 증감 표시 |
| (확장) 품목코드 | 클릭시 해당 품목의 품목코드별 상세 매출 팝업/패널 |

#### 화면 ④-A: 원가 분석 (PPT 슬라이드 8 대응)

| 요소 | 설명 | 데이터 소스 |
|------|------|-----------|
| 사업부별 원가율 추이 | 분기별 원가율 변동 차트 | 월별손익 (매출원가/매출) |
| 사업부별 원가율 테이블 | 전년동기비 원가율 증감(%p) | 월별손익 |
| 품목별 원가율 드릴다운 | 사업부 클릭 → 품목별 매출/원가/원가율 | S_C_raw ✅ |

> 원가는 S_C_raw에 품목별 데이터가 있으므로 "어떤 품목의 원가율이 올라갔는지"
> 드릴다운으로 확인 가능합니다.

#### 화면 ④-B: 비용 분석 (PPT 슬라이드 9 대응)

**데이터 소스**: 월별손익(배부 후 사업부별 금액) + RAW(E)(배부 전 세부 항목별 금액)

| 요소 | 설명 | 데이터 소스 |
|------|------|-----------|
| 전사 비용 총괄 | 비용 대분류별(구분2) 금액/비율/전년비 — PPT 비용분석 슬라이드와 동일 형태 | 월별손익 |
| 사업부별 비용 배분 | 각 비용 항목이 사업부별로 얼마씩 배분되었는지 (배부 후 결과) | 월별손익 |
| 비용 세부항목 드릴다운 | 구분2 클릭 → 구분3(세부항목)별 금액 + 직접귀속/공통 구분 표시 | RAW(E) ✅ |
| 전년동기비 | 비용 항목별 증감 테이블 | 월별손익 + RAW(E) |

**비용 드릴다운 경로 (RAW(E) 기반)**:

```
[Level 0] 전사 비용 총괄 (월별손익)
  ├─ 영업판관비: 123억 (전년비 +15억)
  ├─ 판매대행수수료: 39억
  ├─ 매출변동비: 32억
  ├─ 영업관리비: 18억
  ├─ 일반관리비: 44억
  ├─ 비효율/비경상: 13억
  └─ R&D비용: 117억 (R 59억 + D 58억)
      │
      ▼ (비용 항목 클릭)
[Level 1] 세부 항목별 분석 (RAW(E) 구분3)
  예: 영업판관비 클릭 →
  ├─ 영업비용:    22억 (ETC 직접 22억)
  ├─ 마케팅비용:   28억 (ETC 28억, CH 3억...)
  ├─ 영업인건비:   32억 (ETC 32억, CH 4억...)
  ├─ 마케팅인건비:   6억
  ├─ 영업직접비:    8억
  └─ 광고비:       8억 (ETC 8억, CH 3억, 건기식 8억)
      │
      ▼ (세부 항목 클릭)
[Level 2] 사업구분별 내역
  예: 광고비 클릭 →
  ├─ ETC (직접):   7.7억
  ├─ CH (직접):    2.7억
  ├─ 건기식 (직접):  8.3억
  └─ 공통 (배부대상): 0억
      │
      ✕ 여기까지 (코스트센터/원가요소 레벨은 제공하지 않음)
```

> **핵심**: 기본 화면은 PPT 비용분석 슬라이드와 동일한 형태(전사 비용 대분류 + 사업부별)를 유지하되,
> 드릴다운 시 RAW(E)의 구분3(세부 비용항목) 레벨까지 확인 가능합니다.
> R&D비용은 배부 결과(월별손익)의 R(연구)/D(개발) 금액만 표시하며, 배부 비율은 표시하지 않습니다.

## 5. 사업부별 드릴다운 경로 상세

### ETC
```
ETC 매출 (월별손익)
 ├─ 제품 (제상=제품)
 │   ├─ 자체 (중분류=자체)
 │   │   ├─ 가군 (수익군=가) → 펙수클루, 크레젯, 엔블로, 클로아트, 리토바젯, 액시드, 올로맥스, 안플원 ...
 │   │   ├─ 나군 (수익군=나) → 품목들...
 │   │   ├─ 다군 (수익군=다) → 품목들...
 │   │   └─ 라군 (수익군=라) → 품목들...
 │   └─ 라이선스 (중분류=라이선스)
 │       ├─ 나/다/라군 → 품목들...
 └─ 상품 (제상=상품)
     └─ 코프로 (중분류=코프로)
         ├─ 나군 → 릭시아나, 크레스토, 세비카, 제미글로 등
         ├─ 다군 → 리브레, thynC, 모비케어 등 (디지털헬스케어)
         └─ 라군 → 기타 상품들
```

### 나보타
```
나보타 매출 (월별손익)
 ├─ 국내 (중분류=국내) → 나보타, 브이올렛
 └─ 수출 (중분류=수출) → 미국(Evolus), 브라질, 태국, 사우디, 터키, 캐나다, 유럽국가들...
```

### CH
```
CH 매출 (월별손익)
 ├─ 명품군 (중분류=명품군) → 우루사, 임팩타민, 이지덤, 이지엔6, 베아제
 └─ 기타품목 (중분류=기타품목) → 우루샷, 모바렌, 마그온, 렛잇비 등
```

### 건기식
```
건기식 매출 (월별손익)
 └─ 건기식 (중분류=건기식) → 에너씨슬(서브: 퍼펙트샷/플래티넘/베이직/콜레다운/집중샷...), 닥터베어(서브: EX시리즈/RX시리즈), 합쎈, 세노메가 등
```

### 글로벌
```
글로벌 매출 (월별손익)
 ├─ 해외사업(중국) → 뉴란타 등
 ├─ 해외사업(태국) → 에포시스, 디옥타 등
 ├─ 해외사업(필리핀) → 우루사 등
 ├─ 해외사업(멕시코) → 펙수클루
 ├─ 해외사업(베트남) → 가바펜틴 등
 ├─ 해외사업(인도네시아) → 에포시스 등
 └─ 해외사업(기타) → 화장품, 이지덤 등
```

### 수탁

## 6. UI/UX 상세 설계

### 6-1. 공통 컴포넌트

- **PeriodSelector**: 분기/누적/월별 조회 기간 선택
  - 분기 모드: 25.1Q, 25.2Q, 25.3Q, 25.4Q
  - 누적 모드: 25년 상반기, 25년 3분기누적, 25년 연간
  - 월별 모드: 25.01 ~ 25.12
- **ComparisonBadge**: 전년동기비 증감 표시 (▲12.4% 빨간색 / ▼3.2% 파란색)
- **DrilldownTable**: 행 클릭 시 하위 레벨로 확장되는 테이블
- **WaterfallChart**: 매출/이익 증감 요인 워터폴 차트
- **TrendChart**: 분기별/월별 추이 라인차트
- **Breadcrumb**: 현재 드릴다운 위치 표시 (전사 > ETC > 자체 > 가군 > 펙수클루)

### 6-2. 색상 및 스타일

- 기존 PPT 톤 참조 (주황/노란 헤더 톤)
- 증가: 파란/검정, 감소: 빨간
- 사업부별 구분 색상 고정

### 6-3. 반응형 (모바일 대응 필수)

데스크탑(발표용) 기준으로 설계하되, 평가자가 휴대폰으로도 접속하므로 **처음부터 반응형으로 구현**.
Tailwind 브레이크포인트: `sm`(640px), `md`(768px), `lg`(1024px), `xl`(1280px)

| 요소 | 데스크탑 (xl 이상) | 모바일 (sm~md) |
|------|-------------------|---------------|
| 레이아웃 | 좌측 사이드바 + 메인 | 하단 탭 네비게이션 또는 햄버거 메뉴 |
| 손익 테이블 (44행×8열) | 전체 표시 | 가로 스크롤 + 첫 열(항목명) 고정, 또는 사업부 1개씩 선택 |
| 드릴다운 테이블 | 행 클릭으로 확장 | 터치 탭으로 확장/축소 (동일) |
| 차트 | 고정 너비 | `responsiveContainer` 100% (Recharts 기본 지원) |
| KPI 카드 | 가로 3개 | 세로 스택 또는 가로 스크롤 |
| Breadcrumb | 전체 경로 | 축약 (현재 위치 + 상위 1단계) |
| 기간 선택기 | 탭 형태 | 드롭다운 |

> **구현 원칙**: Tailwind의 `md:`, `lg:` 접두사를 활용하여 하나의 컴포넌트로 양쪽 대응.
> 모바일 퍼스트로 코딩하고, 데스크탑에서 확장하는 방식.

### 6-4. 배포 고려사항

- **정적 빌드 구조 유지**: React 빌드 결과물(HTML/CSS/JS + JSON)만으로 동작하도록 설계
  - 백엔드 의존 없음, 별도 서버 불필요
  - `npm run build` → `dist/` 폴더만 있으면 어디든 배포 가능
- **배포 방식은 완성 후 결정**: 사내 서버, 클라우드 호스팅, 접근 제어 방식 등은 앱 완성 후 최선의 방법으로 진행
- **Read-Only**: 정적 JSON 기반이므로 별도 조치 없이 읽기 전용

## 9. 엑셀 → JSON 변환 스크립트 사양

### excel_to_json.py

입력: 월별손익.xlsx, S_C_raw.xlsx, RAW_E_{2022~2025}.xlsx (4개)
출력: pl_monthly.json, sales_cost_summary.json, sales_cost_raw.json, expense_detail.json

핵심 로직:
1. 월별손익 "실적" 시트 → 45행 단위 블록 파싱 (44항목 + 1빈행)
2. 월별손익 "26년목표" 시트 → 동일 구조로 type="목표"
3. S_C_raw "요약" 시트 → 행 단위 직접 매핑
4. S_C_raw "RAW" 시트 → 행 단위 직접 매핑
5. RAW_E "RAW(E)" 시트 → 구분1~4 + 사업구분 + 월별금액(1~12)으로 집계
   - 구분1='제외1' 행 제외
   - 월별 컬럼(1~12) → 각각 별도 레코드로 변환
   - 코스트센터/원가요소 레벨은 포함하지 않음 (구분3 + 사업구분까지만)
6. 단위 변환 없음 (월별손익은 억원 그대로, S_C_raw/RAW_E는 원 그대로)
7. NaN → null 처리
8. '0 → null 처리 (제상, 수익군 등의 더미값)

### RAW(E) 컬럼 매핑

| RAW(E) 컬럼 | JSON 키 | 비고 |
|-------------|---------|------|
| 구분1 | category1 | 공통비/영업판관비/영업관리비/일반관리비/R&D비용/비효율비경상 |
| 구분2 | category2 | 월별손익 비용분류1과 대응 |
| 구분3 | category3 | 세부 비용항목 (드릴다운 Level 1) |
| 구분4 | category4 | 추가 세분류 (있는 경우) |
| 사업구분 | bizUnit | 직접귀속 사업부 또는 "공통" |
| 1~12 (월별 금액) | amount | 각 월별 레코드로 분리 |

### RAW(E) 연도별 차이점

| 항목 | 2022~2023 | 2024~2025 |
|------|-----------|-----------|
| 컬럼 수 | 25개 | 26개 (Unnamed 추가) |
| col 9 (원가요소명) | ` (백틱) | 원가요소명 |
| R&D 조견표 | R(연구)/D(개발)만 (12컬럼) | +직접/신약 구분 (34컬럼) |
| R&D 배부 | 전체 비율로만 배부 | 직접/신약 4단계 상세 배부 |

> R&D 조견표의 직접/신약 구분은 드릴다운 레포트에서 사용하지 않습니다.
> R&D는 월별손익의 배부 결과(R/D 금액)만 표시합니다.

| PPT 슬라이드 | 대시보드 화면 | 드릴다운 추가 |

| 나보타 국가별 | 나보타 상세 화면 | 국가→거래처 드릴다운 |
| 원가 분석 | 원가 분석 화면 | 사업부→품목별 원가율 |
| 비용 분석 | 비용 분석 화면 | 구분2→구분3→사업구분별 드릴다운 (RAW(E)) |
